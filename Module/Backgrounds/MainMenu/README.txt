MAIN MENU BACKGROUNDS
=====================

Put your own pictures in this folder and Customisable UI shows one of them behind the
main menu, in place of the game's video.

  - PNG or JPG files (.png, .jpg, .jpeg), with any name.
  - One is chosen at random each time the main menu appears. Put in one file to always
    get that one. Files are picked up when the main menu next appears, so you can add
    or remove them while the game is running.
  - 1920x1080 (16:9) or larger looks best. Please keep each picture to 4K (3840x2160)
    or smaller: the game holds each picture it has shown in memory.
  - A picture that is a different shape from your screen is cropped to fit, keeping its
    middle. To show all of it instead (squashed), set Picture fit to "Stretch to fit".

The game's menu video keeps playing underneath your picture, so you still hear its
music. This file is ignored; leave it where it is.

To switch it off: Options > Mod Options > Customisable UI > 11. Backgrounds > Use custom
backgrounds. The vanilla-look hotkey (default Ctrl+Shift+U) also brings the game's own
back for a moment.

If a picture doesn't appear, look in
  Documents\Mount and Blade II Bannerlord\Logs\CustomisableUI.log
for a line starting "Custom background loaded" (it worked) or an error naming the file.

Note: updating or reinstalling the mod may replace this folder, so keep a copy of your
pictures somewhere else.
