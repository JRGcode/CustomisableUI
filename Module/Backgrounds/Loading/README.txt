LOADING SCREEN BACKGROUNDS
==========================

Put your own pictures in this folder and Customisable UI shows them on the loading
screens, in place of (or mixed with) the game's own.

  - PNG or JPG files (.png, .jpg, .jpeg), with any name.
  - Each loading screen shows one picture, chosen at random, and never the same one
    twice running if you have more than one. You can have as many as you like.
  - Files are picked up shortly after you add them, so you can add or remove them
    while the game is running. The first few seconds after adding a file, a loading
    screen may still show the game's picture while the new one is loaded.
  - 1920x1080 (16:9) or larger looks best. Please keep each picture to 4K (3840x2160)
    or smaller: the game holds each picture in memory.
  - A picture that is a different shape from the area it fills is cropped to fit,
    keeping its middle. To show all of it instead (squashed), set Picture fit to
    "Stretch to fit".

WHICH PICTURES THE LOADING SCREENS SHOW
  Options > Mod Options > Customisable UI > 11. Backgrounds > Loading screens:
    My pictures only .......................... every loading screen shows one of yours
    My pictures and the game's, mixed ......... about half show one of yours, half the game's
    The game's pictures only (none of mine) ... yours are not used for loading screens

This works with the War Sails expansion too, which has its own set of loading pictures.

The game reuses a couple of its loading pictures elsewhere (behind some campaign menus,
and on the profile selection screen). Those show one of yours too, unless you choose
"The game's pictures only". This file is ignored; leave it where it is.

To switch everything off: set "Use custom backgrounds" in the same group to off.

If a picture doesn't appear, look in
  Documents\Mount and Blade II Bannerlord\Logs\CustomisableUI.log
for a line starting "Custom background loaded" (it worked) or an error naming the file.

Note: updating or reinstalling the mod may replace this folder, so keep a copy of your
pictures somewhere else.
